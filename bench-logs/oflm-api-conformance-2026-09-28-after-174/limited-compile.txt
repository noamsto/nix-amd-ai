LIMITED build guard for embed-task-prompt.patch (#174 / PR #182 finding 2)

The finding: task_names()/TaskResolution/resolve_task and the handle_embeddings
resolution block use embedding_task_type_t at file scope, but that enum comes
from auto_embedding_model.hpp, which rest_handler.hpp includes only under
#ifndef FASTFLOWLM_LINUX_LIMITED_MODELS. With the define set, rest_handler.cpp
did not compile. Fix: put the helpers and the resolution block under the same
#ifndef as the embed loop they feed.
